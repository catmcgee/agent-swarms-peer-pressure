# Decision log

Design decisions and deviations are append-only. Superseded decisions remain visible.

| Date | Decision | Rationale |
|---|---|---|
| 2026-08-27 | Name the project SwarmStop. | Short working name tied to the central stopping question. |
| 2026-08-27 | Use AgentAbstain as the primary executable substrate. | It provides paired tasks, runtime triggers, stateful sandboxes, and deterministic commit checks. |
| 2026-08-27 | Import AuthorityBench semantics through an adapter rather than vendoring it. | The authority lattice is useful, while the executable abstention environments are the stronger behavioral substrate. |
| 2026-08-27 | Make yoked authentic peer boards the confirmatory design and live swarms a targeted replication. | This separates causal peer effects from endogenous swarm dynamics and controls compute cost. |
| 2026-08-27 | Treat delegation as a critical-action attempt. | A focal agent should not evade the boundary by asking a peer to act. |
| 2026-08-27 | Analyze a common two-round horizon and use survival analysis for longer budgets. | Raw cumulative risk is mechanically higher when more action opportunities exist. |
| 2026-08-27 | Pin upstream versions and fetch them into ignored directories. | This preserves attribution, keeps the repository small, and makes provenance explicit. |
| 2026-08-27 | Use a provisional 12-task pilot balanced across six categories and twelve primary domains. | The pilot needs operational and trigger diversity before scaling task count. |
